# dknr-matter

Pont Matter pour les projets DKNR : publie les entités DKNR (lues sur MQTT) comme des appareils Matter, pilotables en local depuis Alexa, Home Assistant, Apple Maison ou Google Home.

Projet en cours de conception : voir [docs/CONCEPTION.md](docs/CONCEPTION.md).

Documentation des projets DKNR : https://dknr-domotic.github.io
